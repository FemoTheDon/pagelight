# PageLight for Chromebook

PageLight by Breadbaskets: an EPUB, PDF and MOBI reader with focus mode and night mode.

Install it on a Chromebook from https://femothedon.github.io/pagelight/ (Chrome's install button in the address bar, or menu › Cast, save and share › Install page as app).

Your books are kept in the app's own storage on the device. Nothing is uploaded.
